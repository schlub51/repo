An audio-reactive wave for Spotify, Apple Music, the Lock Screen, Home Screen, Lock Screen media controls, and the Jade Control Center media module.

Mitsuha Six and a Half is a repair fork of Mitsuha Six, focused on iOS 16/rootless reliability and cleaner Spotify colors.

Screenshots

What's New

  • Spotify in-app wave on the current Now Playing screen
  • App Store Spotify audio through a loopback path
  • Dynamic+ mode using Spotify's own ambience color for a punchier, more native-looking wave
  • Spotify Gradient Fill, so the filled wave fades into the player instead of showing a hard edge while scrolling
  • Apple Music Dynamic color fixes
  • Lock Screen, Home Screen, media card, and Jade Control Center cleanup

Known Issues

  • Spotify Canvas covers the in-app wave
  • Spotify in-app and Dynamic+ depend on Spotify internals, so a future Spotify update may require a tweak update
  • Lock Screen media controls / artwork tap can still be intermittent when Lock Screen Background is active
  • Other iOS/rootless combinations are untested

Compatibility

Tested on iOS 16.4.1 rootless with Dopamine. iOS 15 and iOS 17 are untested.

Dependencies

Installs libmitsuha65 and AudioSnapshotServer 2 automatically.
