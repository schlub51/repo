IPARanger++ is an enhanced build of IPARanger (a GUI for ipatool) with extra options and tweaks on top of the version by 0xkuj.

What's different

  • Extra options in the interface
  • Downloads folder spacing / layout tweaks
  • Various quality-of-life additions

Builds

  • Rootless (Dopamine)
  • Rootful (iOS 13 compatible)

Based on IPARanger by 0xkuj. Enhanced build maintained by schlub51.
